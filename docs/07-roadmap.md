# Implementation Roadmap

The project will be built in strict, incremental phases to ensure a working product at every step.

- **PHASE 1**: Architecture + database + project setup (Monorepo, Docker, Docs).
- **PHASE 2**: Authentication + Role-Based Access Control (RBAC).
- **PHASE 3**: Student Profile management (CRUD for skills, education, projects).
- **PHASE 4**: Assessment Engine (Question bank, timers, auto-scoring).
- **PHASE 5**: ML Training Pipeline (Jupyter notebooks, dataset generation, model selection).
- **PHASE 6**: ML API Service (FastAPI, model serving, SHAP integration).
- **PHASE 7**: Readiness Dashboard (Frontend UI connecting to ML service data).
- **PHASE 8**: Skill Gap Engine (Role-skill matrix logic).
- **PHASE 9**: Recommendation Engine (Rule-based learning path generation).
- **PHASE 10**: Resume Analyzer (PDF parsing, basic keyword matching).
- **PHASE 11**: Mentor Dashboard (Assigned students, overview metrics).
- **PHASE 12**: Admin Dashboard (Organization-wide metrics, user management).
- **PHASE 13**: Advanced Analytics (Charts, trends, exportable reports).
- **PHASE 14**: Testing (Unit, Integration, E2E).
- **PHASE 15**: Docker + Deployment (CI/CD workflows, final polish).
